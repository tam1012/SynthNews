What it does

Reading the news in a second language is slow, and most feeds are noisy. SynthNews removes that friction: it watches the sources you care about, fetches the full article text, filters out promotional or low-value posts, and produces a tight summary and translation for each story. The result is a fast-reading feed where every item is already in Vietnamese.

How it works

Three automated stages run around the clock, with no manual work required.

1

Collect

Scheduled jobs poll RSS feeds, news websites, Reddit and Vietnamese forums, then fetch the full article text from each new story.

2

Summarize & translate

Each article is sent to a large language model that writes a short Vietnamese summary and a one-line takeaway, with retries and validation so no empty or malformed output reaches the reader.

3

Read

Stories appear in a fast, mobile-first reader with filters by source and topic, plus a daily digest that bundles the day's most important news.

Features

Built as a real, running product — not a prototype.

AI summaries & translation

Multi-provider model routing with automatic repair and safe fallbacks, so summaries stay usable even when a provider refuses or truncates a response.

Multi-source aggregation

RSS, standard news websites, Reddit and forum scrapers — including browser-based scraping for sites that block plain HTTP requests.

Personalized feed

Filter by source or topic, save articles for later, mute tags, and mark stories as read. The feed remembers your choices.

Daily digest

Every day, the most significant stories are grouped into a single digest so you can catch up in a couple of minutes.

Fast, offline-friendly reader

A mobile-first progress web app with offline caching, so previously loaded news stays readable without a connection.

Open source

The full codebase is public on GitHub and can be self-hosted with Docker Compose.

Built with

A TypeScript monorepo running in production on a single cloud VM.

  • TypeScript
  • Node.js + Hono
  • PostgreSQL 16
  • React + Vite
  • Python scraping sidecar
  • Multi-provider AI routing (Claude, Gemini, OpenAI-compatible)
  • Docker Compose
  • GitHub Actions CI/CD

About

SynthNews is an independent, bootstrapped project founded in 2026. It started as a personal tool for reading international tech and world news in Vietnamese, and has since grown into a continuously running service that processes hundreds of thousands of articles.

We are not a venture-funded company and we are not affiliated with any news organization. The project is built and maintained by a single founder, with an emphasis on reliability, low running cost, and a clean reading experience.

Because the code is open source, anyone can read exactly how the aggregation, filtering and AI summarization pipeline works.
